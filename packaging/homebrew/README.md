# maneeshth/homebrew-tap

Homebrew tap for [Desktop Pet](https://github.com/maneeshth/yourpetproject).

```bash
brew tap maneeshth/tap
brew install --cask desktop-pet
```

Uninstall with `brew uninstall --cask desktop-pet` (add `--zap` to also remove
the app's settings folder).

This directory is the source of the `maneeshth/homebrew-tap` repository: copy
`Casks/` and this README there on each release.
